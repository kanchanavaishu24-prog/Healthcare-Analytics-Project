# Healthcare Analytics Project

This project analyzes healthcare data to identify patient trends, billing patterns, medical conditions, admission patterns, and healthcare insights.

## Tools Used
- Excel - Data Cleaning
- Python - Data Analysis
- SQL - Data Querying & Business Insights
- Power BI - Interactive Dashboard

## Project Work
- Cleaned and prepared healthcare data using Excel
- Performed data analysis using Python and Pandas
- Analyzed healthcare data using SQL
- Created business-focused SQL queries using GROUP BY, CASE, HAVING, Subqueries, CTEs, and Window Functions
- Created an interactive Power BI dashboard
- Analyzed patient count, billing, medical conditions, test results, and admission types

## Files Included
- Healthcare_Cleaned.xlsx - Cleaned Dataset
- DASHBOARD CLEANED.pbix - Power BI Dashboard
- 01_Project_Summary.sql - SQL Summary Queries
- 02_SQL_Analysis.sql - SQL Analysis Queries

## Key Metrics
- Total Patients: 55,500
- Total Hospitals: 39,876
- Medical Conditions: 6
- Average Billing: 25,539.32
- Average Length of Stay: 15 days

## Key Insights
- Patient distribution across different medical conditions
- Test result distribution
- Admission type analysis
- Billing amount analysis
- Hospital and insurance provider analysis

## Power BI Dashboard
The dashboard provides an interactive overview of:
- Total Patients
- Total Billing Amount
- Average Billing Amount
- Medical Conditions
- Test Results
- Admission Types
- Medical Condition and Test Result slicers

## Conclusion
This project demonstrates how Excel, Python, SQL, and Power BI can be combined to clean, analyze, and visualize healthcare data. The analysis helps identify important patient, billing, admission, and medical trends that can support data-driven decision-making.
